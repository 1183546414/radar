# 归档说明

本目录存放重组前的历史代码与重复目录，**日常开发请使用 `src/radar/` 与 `data/`**。

| 子目录 | 原位置 |
|--------|--------|
| `legacy_model/` | `model/` |
| `legacy_final_code/` | `final_code/` |
| `legacy_dataset/` | `dataset/`（空壳或残留） |
| `legacy_data_4_root/` | 根目录 `data_4/` |
| `legacy_result/` | `result/` |
| `legacy_radar_bundle/` | `radar-10.11/` |

确认新结构运行正常后，可自行删除本目录以节省空间。
